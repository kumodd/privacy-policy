UOAI Chat Privacy Policy

Official privacy policy for UOAI Chat (com.uoai.chat) — a private, on-device AI conversational assistant and document intelligence client for Android.

100% Offline AI Chat • Zero Cloud Uploads • Zero Accounts • Zero Tracking

UOAI Chat was engineered from the foundation up to provide an uncompromisingly private conversational AI experience. Your conversations, attachments, questions, and responses never leave your physical device. The app communicates strictly with your local on-device UOAI Provider service over loopback (127.0.0.1), with zero internet telemetry, zero external cloud servers, and zero advertising SDKs.

1. Purpose of UOAI Chat

UOAI Chat is a standalone, lightweight conversational client app for Android. It connects directly to the local UOAI Provider app (com.uoai.provider) installed on your device to stream responses from open-weight local models (like Gemma). It provides rich markdown rendering, local document question-answering, and prompt customization without ever contacting a cloud server.

2. Conversation History, Prompts, and Answers

  • Local In-Memory Handling: Chat turns, system prompts, and responses are kept solely within the application's local process memory and private app state.
  • No Cloud Sync: There are no user accounts, no cloud databases, and no backup servers storing your discussions.
  • Ephemeral By Design: Tapping the "New Chat" icon instantly discards the in-memory chat session.

3. Document Attachments & On-Device Text Extraction

UOAI Chat allows users to attach files (PDF, Word DOCX, Excel XLSX, PowerPoint PPTX, RTF, HTML, TXT, code files, and logs) to chat with their documents offline.

  • 100% Local Text Extraction: All file parsing occurs on-device using embedded libraries (such as PDFBox-Android and native UTF-8 stream readers).
  • Zero Remote Uploads: Neither your original files nor the extracted text are uploaded to any external or cloud server.
  • Scoped System Picker: Files are chosen exclusively through the Android Storage Access Framework (SAF). UOAI Chat never has broad access to your photo library, download folder, or internal storage.
  • Ephemeral Attachment Lifetime: Document text is held in memory only for the context of the active query, and is purged when you clear or start a new chat.

4. Communication with Local UOAI Provider

UOAI Chat does not execute AI models inside its own process. Instead, it queries the local UOAI Provider app:

  • Strict Loopback Only: All requests travel over Android's local loopback interface (http://127.0.0.1:8765). No traffic is transmitted across Wi-Fi or cellular networks.
  • Keystore-Secured Authentication: UOAI Chat registers with UOAI Provider via an OS-verified Activity result contract. The resulting authentication token is saved securely in the hardware-backed Android Keystore and presented in loopback HTTP headers (Authorization: Bearer <token>).

6. Third-Party SDKs, Advertising & Analytics

  • Zero Advertising SDKs: No ads, sponsors, or marketing trackers.
  • Zero Analytics / Telemetry SDKs: No Firebase, Google Analytics, Mixpanel, or Segment.
  • Zero Crash Telemetry: No third-party crash reporters (e.g. Sentry, Bugsnag).
  • Zero Profiling: We do not track or store your device identifiers or usage habits.

8. User Control & Data Deletion

You have full, immediate control over all conversational data:

  1. Clearing Active Chat: Tap the "New Chat" icon at the top of the chat view to instantly clear current messages and attachments from memory.
  2. Full Data Wipe: Go to Settings → Apps → UOAI Chat → Storage → Clear Storage / Clear Data to wipe all app state, settings, and stored credentials.
  3. Uninstalling: Removing UOAI Chat automatically and permanently purges all private data from your phone.

9. Children's Privacy

UOAI Chat does not collect, transmit, or store personal information from any user, including children under 13. It is fully compliant with COPPA and GDPR.
