100% On-Device • Zero Cloud Inference • Zero Accounts • Zero Telemetry

UOAI Provider runs open-source Large Language Models (such as Gemma) entirely within your device's physical hardware (CPU, GPU, NPU). Your prompts, model weights, and AI responses never leave your phone. We operate no remote inference servers, collect no telemetry, track no device identifiers, and require no account registration.

1. Purpose and Architecture of UOAI Provider

UOAI Provider acts as a shared, local system utility on Android. Rather than requiring multiple apps to each bundle heavy multi-gigabyte models and exhaust your device RAM, UOAI Provider hosts a single loaded model in memory and provides a standardized OpenAI-compatible loopback API for approved client applications on the same physical device.

2. Data Stored Locally on Your Device

All data processed by UOAI Provider is confined strictly to the app's internal sandbox:

  • AI Model Files: LiteRT-LM (.litertlm), MediaPipe (.task), or GGUF model files stored in private app storage. These are downloaded directly from open-source repositories (such as Hugging Face) upon direct user initiation, or imported manually from device storage.
  • Client Application Registrations: The package name, friendly label, and SHA-256 signing certificate fingerprint of client apps you explicitly authorize via Android OS Activity results.
  • Cryptographic Access Tokens: Locally generated random tokens stored in the hardware-backed Android Keystore. These tokens are used solely to verify inter-process requests from approved client apps.
  • Inference Audit Trail (Metadata Only): Optional local logs containing timestamps, client package names, token counts, and execution latency. Prompt text, system instructions, and generated completions are never logged or saved in audit records.

3. Loopback-Only Local Network Architecture

The embedded HTTP/SSE server (powered by Ktor CIO) binds strictly to 127.0.0.1:8765 (loopback interface).

  • It never binds to 0.0.0.0 or external interfaces.
  • It cannot be reached from the internet, local Wi-Fi, or cellular networks.
  • It only accepts requests originating from within the local Android OS kernel on the same device.

4. Device Permissions & Declarations

UOAI Provider requests only the minimal permissions required for on-device operation:

android.permission.INTERNET Normal Loopback Sockets & Model Downloads: Required by Android to open local TCP sockets to 127.0.0.1 for inter-process communication with approved local client apps. It is also used to download public open-source model weights from Hugging Face when initiated by the user. No private data is ever uploaded.
FOREGROUND_SERVICE &

7. User Control & Data Deletion

Users maintain full sovereignty over all on-device data:

  1. Revoking Client Access: Revoke any approved client application immediately from the Clients tab.
  2. Deleting Model Files: Delete downloaded AI model bundles from the Models screen at any time to reclaim device storage.
  3. Full Data Wipe: Clear all app data via Settings → Apps → UOAI Provider → Storage → Clear Storage.
  4. Uninstalling: Removing the app completely purges all private storage, Keystore secrets, and logs.

8. Children's Privacy

UOAI Provider does not collect, transmit, or store personal information from anyone, including children under 13 years of age. It complies with COPPA and GDPR.
