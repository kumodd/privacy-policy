Privacy Policy Hub

Official privacy documentation and Google Play Console compliance disclosures for the Universal Offline AI applications.

Core Commitment: 100% On-Device • Zero Cloud • Zero Tracking

The Universal Offline AI ecosystem ensures that all model loading, AI generation, and document processing happen entirely on your physical device. We operate no cloud inference servers, track no user identities, and integrate zero advertising or telemetry SDKs.

UOAI Provider

com.uoai.provider

Shared on-device AI inference engine for Android. Hosts local Gemma models in memory and exposes a secure loopback API (127.0.0.1:8765) for approved apps.

  • Strict loopback-only network binding
  • Keystore-backed cryptographic tokens
  • Zero prompt or response logging
  • Fully compliant Google Play Data Safety

UOAI Chat

com.uoai.chat

Private conversational AI assistant and document intelligence client. Queries UOAI Provider over loopback with 100% on-device document text extraction.

  • Local in-memory conversation state

  • Scoped Storage Access Framework

UOAI Keyboard

100% offline, ad-free Android keyboard with on-device Gemma writing & reply tools, multilingual layouts, clipboard history, and offline voice typing.
